# Student Record Management System

A beginner-friendly Python project that manages student records.

## Features
- Add student records
- View all students
- Search for students
- Update student details
- Delete student records
- Display high scorers

## Technologies Used
- Python
- JSON for data storage

## How to Run
1. Install Python.
2. Download `student_record_system.py`.
3. Open a terminal in the project folder.
4. Run `python student_record_system.py`.
